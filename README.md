# Claw Dashboard

A lightweight local dashboard for monitoring laptop system health, with AI-powered telemetry reports.

## Features

- **Real-time monitoring**: CPU usage, temperature, power (watts), memory, C: drive free space — refreshed every 1 second
- **CPU & Memory trend charts** for the last 60 seconds
- **Process monitoring**: Top 10 CPU and memory processes, refreshed every 3 seconds
- **DeepSeek balance** with daily spending tracker, refreshed every 1 minute
- **CPU temperature** via LibreHardwareMonitor remote web server
- **CPU power** (watts) via LibreHardwareMonitor
- **Dual-ring display**: temperature ring (0–100°C, red gradient) + power ring (0–40W, gold gradient)
- **SQLite telemetry logging**: 1-minute interval, WAL mode, 30-day auto-cleanup
- **Auto-generated telemetry reports**: Interactive HTML reports with Chart.js charts, Chinese anomaly analysis, and process breakdowns

## Telemetry Reports

Reports are generated by the bundled `telemetry-report` skill (`skills/telemetry-report/`).

```powershell
# From the dashboard directory:
python skills/telemetry-report/scripts/generate_report.py --db data/telemetry.db --range 24h

# Ranges: 1h | 24h | 7d | 30d | custom
```

Reports include:
- Summary metric cards (CPU, temperature, power, memory, disk)
- Interactive Chart.js line charts (5 metrics)
- Chinese overall health assessment with recommendations
- Multi-dimensional anomaly detection (temperature, CPU, memory, rapid metric changes)
- Per-anomaly context analysis (what processes were running, system state at the time)
- Hourly breakdown table
- Process Top 10 lists

Reports auto-save to `public/reports/` and appear at the bottom of the Dashboard.

## Requirements

- Node.js 18 or newer
- Windows (C: drive monitoring, process monitoring, LibreHardwareMonitor)
- Python 3 (for report generation)
- [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) with remote web server enabled (for temperature and power)

## Setup

Create a `.env` file in the project root:

```env
DEEPSEEK_API_KEY=sk-your-key-here
PORT=3000
LIBRE_HARDWARE_MONITOR_URL=http://192.168.18.154:8085/data.json
CPU_POWER_SENSOR_ID=/intelcpu/0/power/0
CPU_TEMP_SENSOR_ID=/intelcpu/0/temperature/18
```

Install dependencies:

```powershell
npm install
```

## Start

```powershell
node server.js
```

Open:

```text
http://localhost:3000
```

## API

| Endpoint | Description | Refresh |
|----------|-------------|---------|
| `GET /api/system` | CPU + memory + temp + power | 1s |
| `GET /api/drive` | C: drive free space | 10s |
| `GET /api/deepseek` | DeepSeek balance + daily usage | 60s |
| `GET /api/processes` | Top 10 CPU + memory processes | 3s |
| `GET /api/reports` | List generated telemetry reports | 30s |

## Notes

DeepSeek daily usage is calculated as:

```text
initial balance for today - current balance
```

If the account is topped up during the day, the value may become negative.

## CPU Temperature & Power

Both are read from LibreHardwareMonitor's remote web server. Default sensors:

- Temperature: `/intelcpu/0/temperature/18` (CPU Package)
- Power: `/intelcpu/0/power/0` (CPU Package)

If sensor paths change, update `CPU_TEMP_SENSOR_ID` and `CPU_POWER_SENSOR_ID` in `.env`.
